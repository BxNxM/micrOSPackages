MicroPython terminal

After connecting, click the terminal and enter your WebREPL password (normally the device's appwd). No password is saved by this console.

Using the Python prompt

Press Ctrl+C to reach the Python prompt (>>>). This stops micrOS, including its web server and automation. Keep this page open to use the console.

To restart micrOS, type import helpers and press Enter, then type 0 and Enter to reboot. Reconnect after startup. Choose 1 instead to open the micrOS shell on the device.

Paste: Ctrl+A, then Ctrl+V (Cmd+V on macOS). Only one WebREPL client can connect at a time. Disconnecting leaves WebREPL enabled until reboot.
